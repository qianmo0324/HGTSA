# MK01–MK10 HGTSA 实现计划

**Goal:** 依据用户提供的《详细复现步骤_格式整理版》，以 Python 实现并运行 BRdata 的 HGTSA 实验流程。

**Architecture:** 不改动原始数据。以唯一工序编号的机器序列表示染色体，DAG 最长路解码；分离遗传操作、混合邻域、TS、实验记录和 SVG 图表。

**Tech Stack:** Python 3.10+，仅标准库，unittest。

**Spec:** 用户确认的聊天设计及 `D:/Desktop/工工2/车间调度/详细复现步骤_格式整理版.docx`；用户明确限定 MK01–MK10，覆盖文档中下载其他数据和 DPdata 调参的要求。

## Global Constraints

- 默认 PS=30、Pc=0.9、Pm=0.1、smallIter=1200、largeIter=15000，每例 10 次。
- 原论文未给出的最大代数作为可配置参数；附加时间限制必须记录，不能将限时结果声称为完整论文实验。
- LB/UB、目标均为原论文表 5 历史参照，不声称为当前最新纪录。
- 不硬编码调度答案，不保证随机启发式达到论文结果。
- 不重复工件编号来推断工序身份；显式保留工序编号，并输出工件编号视图。
- 无 Git 仓库，直接在用户指定项目中创建代码，不创建工作树或提交。

## Review Focus

畸形数据拒绝；不合法分配和有环序列拒绝；修复不丢工序；TS 仅使用可行邻居并禁止逆向移动；断点恢复核对数据指纹和参数。

## Tasks

1. [x] `hgtsa/model.py`、`tests/test_model.py`：手工 makespan、环检测、修复及十例解析；拓扑解码返回 head、tail、关键路径、关键块。
2. [x] `hgtsa/neighborhoods.py`、`hgtsa/genetics.py`、`tests/test_search.py`：邻域可行性、跨机插入与穷举环检测一致、路径重连终点；N8 的 N7 内部移动和块外插入、精确可达性跨机插入、轮盘赌、两类变异。
3. [x] `hgtsa/solver.py`：小算例优化、种子重现、限时可行性、停机原因；逆向移动禁忌与特赦、两级 TS 以及父子合并择优。
4. [x] `run_experiments.py`、`hgtsa/reporting.py`、`plot_results.py`、`tests/test_experiments.py`：每次独立种子、调度 JSON、逐次保存、CSV、RE/MRE、论文参照与 SVG。
5. [x] `README.md`：来源和未严格复现部分；全部测试与十例快速实验，输出图像及实际统计。

验证命令：`python -m unittest discover -s tests -v`；`python run_experiments.py --profile smoke --output results/smoke`。

## 实现裁定与差异

- 用户已要求按新版文档执行并限定现有十例；直接执行，不再重复询问范围。
- N8 参考作者预印本 https://arxiv.org/abs/2109.02843 第 3 节；使用精确 DAG 检查，不采用快速近似评价和全部非改进剪枝。
- k-insertion 以移除工序机器弧后的祖先/后继确定精确可行插入窗口；替代原文印刷存在符号混用的时间不等式，保留无环保证。
- Ren & Wang 2012 正文访问受限，不能确认其逐步修复过程。本实现明确命名为优先级拓扑修复，不冒称该方法的逐行复现。该差异须在 README 与结果元数据披露。
- 仅采用论文最终参数；不运行 06a DOE。

## 验证记录

- 单元及集成测试：17 项通过。回归覆盖窄色块必须有静态工序标签、相邻交换逆向禁忌的等价描述、重绘时数据指纹拒绝。
- `results/smoke`：十例各完成一次 3 秒预算快速检查，仅验证端到端流程，不是论文复现实验；记录来自初版搜索实现，后续禁忌属性修正未重跑此批优化。
- 已保存的十例甘特图用最终绘图代码重绘；逐例检查所有 1414 道工序各有且仅有一个标签；渲染检查 MK01/MK10 无标签缺失。
- 独立只读审查发现两项 P2：逆向相邻交换可能换用另一工序绕过禁忌、重绘可能混入改动后的数据；均已复现并用回归测试修复。另移除了父子合并时额外重复加入 best 的行为。
- 尚未运行正式参数下的 100 次求解，不宣称达到论文 Best/MRE 或时间指标。
